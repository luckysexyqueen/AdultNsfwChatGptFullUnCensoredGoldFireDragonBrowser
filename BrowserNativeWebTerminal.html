📦 npm / GitHub 도구

가상 셸에서 npm --version, npm install <package> 명령을 사용할 수 있습니다(네트워크와 WebContainer 지원 환경 필요). 공개 GitHub 저장소 ZIP은 아래에서 가상 파일시스템으로 가져올 수 있습니다.

🌐 Git 명령 (WebContainer)

터미널에서 npm install isomorphic-git 실행 후 node git-web.mjs clone https://github.com/owner/repo, node git-web.mjs status repo, node git-web.mjs add repo 파일명, node git-web.mjs commit repo "메시지", node git-web.mjs push repo 명령을 사용하세요. GitHub push는 인증 토큰 및 Git 스마트 HTTP를 지원하는 CORS 프록시가 필요할 수 있습니다.

Git 명령 도구 준비 전
