# Optional platform adapters
Use direct uploaded ZIP/source first. GitHub Pages and Cloudflare Pages host static frontends; Node.js or GGUF inference requires separate runtime. Cloudflare Workers provide a serverless runtime with different constraints from local Node.js and native model runners. OnSpace AI, Readdy AI, Manus, ChatGPT, Codex and Grok integrations are file-export/import workflows unless explicit authorized API/tool access exists. Do not claim these services are connected. Preserve original projects, approved model files, credentials (outside exports), and rollback history. Dual GeckoView/Chromium WebView remains independent under custom host.
