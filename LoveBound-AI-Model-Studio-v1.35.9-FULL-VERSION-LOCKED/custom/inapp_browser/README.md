# In-app browser platform targets
Primary targets: Windows x86_64 portable EXE, Android arm64-v8a APK.
Deferred: Linux, Windows x86, Android arm32.
These folders and JSON are **profiles/staging only**. No Electron, Android SDK, Gradle, Java, Python model runner or native libraries are bundled.
Use the target report script to inspect plans. Do not place private keys, credentials or unapproved model weights in distributable web assets.
