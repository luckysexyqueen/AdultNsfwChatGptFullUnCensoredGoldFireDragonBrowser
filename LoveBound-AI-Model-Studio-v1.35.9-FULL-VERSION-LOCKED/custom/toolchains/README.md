# Toolchain catalog
This directory records development tool preferences and command-path inventory only.
It does not include or install IntelliJ IDEA, Android Studio, Apktool M, APKEditorPro, Java, SDKs, npm packages or executables.
Keep third-party licenses, secrets and signing credentials separate. Inventory detects PATH commands only, not all IDE/GUI installations.
Use explicit user-selected, isolated copies for project repair, native integration and eventual build.
